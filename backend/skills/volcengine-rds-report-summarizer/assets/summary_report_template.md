## 一、环境巡检说明

### 1.1 巡检范围

本次汇总面向皮氏咖啡火山引擎生产环境 MySQL PaaS 数据库，统计周期覆盖 {{time_range_summary}} 内生成的 RDS MySQL 巡检报告，共收到 {{report_count}} 份报告，其中纳入本次汇总统计 {{included_count}} 份。

### 1.2 巡检周期

本报告生成时间为 {{report_time}}，默认基于用户指定时间窗口内的巡检结果，输出周报或月报形式的汇总结论。

### 1.3 巡检方式

1. 已开启 MySQL 自动巡检的实例，基于火山引擎自动巡检评分结果进行分析。当前自动巡检按月执行一次，本次汇总默认参考上一个月的巡检结果。
   - 100 分：健康。
   - 80–99 分：良好，存在部分指标需持续关注。
   - 60–79 分：及格，存在至少一项中等及以上风险，建议在两周内完成整改。
   - 60 分以下：不及格，存在多项中等及以上风险，需立即介入处理。
2. 未开启 MySQL 自动巡检的实例，应在本周期内完成自动巡检配置；在自动巡检结果缺失的情况下，本次汇总将基于上一个周期的火山引擎标准监控数据进行补充分析。
